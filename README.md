# Sath Linux 🐧

**Sath Linux** — дистрибутив на базе **Debian Sid** (rolling) с **KDE Plasma 6 на Wayland**. Он собран для повседневной работы, программирования, игр и обучения кибербезопасности: из коробки есть откат системы из меню загрузки, безопасные лаборатории для практики и переключатель режимов Daily / Hack.

> **Статус:** версия 3.0, добавлена Pandora (полноценный голосовой ИИ-ассистент, с которым ты общаешься голосом в обе стороны). Базовая система и установщик собираются скриптом из этого репозитория. Откат на снапшотах, Sath Lab и режимы Hack/Daily появились недавно и ещё проходят тестирование, поэтому возможны баги. Issues и Pull Requests приветствуются.

## ✨ Главные фишки

### 🛟 Откат системы из GRUB (Btrfs + snapper)
Система устанавливается на **Btrfs** с подтомами `@`, `@home`, `@log`, `@cache` и сжатием zstd.

- При первой загрузке установленной системы автоматически настраивается **snapper** и создаётся первый снапшот.
- **Перед каждой операцией `apt` и после неё** создаётся пара снапшотов. Если обновление сломало систему, у тебя есть точка возврата.
- **grub-btrfs** следит за каталогом снапшотов и сам добавляет их в меню GRUB. Выбираешь рабочий снапшот при загрузке и возвращаешься в нормальное состояние.
- Снапшоты по расписанию (почасовые, дневные, недельные) с автоматической очисткой старых.
- Проверить снапшоты: `sudo snapper list`.

> Ограничение: снапшоты защищают файлы системы, но не загрузчик и не раздел ESP. Закрепление отката командой `snapper rollback` пока в доработке.

### 🧪 Sath Lab — полигоны для практики в один клик
Лаунчер уязвимых приложений для обучения ИБ. Работает в **rootless Podman**: контейнеры не требуют root и не ломают основную систему зависимостями.

| Полигон | Адрес |
|---|---|
| DVWA | http://127.0.0.1:8081 |
| OWASP Juice Shop | http://127.0.0.1:3000 |

- Порты открываются **только на `127.0.0.1`**, из сети полигоны недоступны.
- Запуск из меню приложений («Sath Lab») или из терминала:
  ```bash
  sath-lab                 # графическое меню (kdialog)
  sath-lab start dvwa      # запустить и открыть в браузере
  sath-lab stop juice      # остановить
  sath-lab reset dvwa      # удалить контейнер (чистое состояние)
  sath-lab status          # статус всех полигонов
  ```
- Образы скачиваются при первом запуске, нужен интернет.
- DVWA после запуска нужно один раз инициализировать на странице `/setup.php` («Create / Reset Database»).
- Используй полигоны только для обучения на собственных стендах.

### 🔀 Режимы Daily / Hack (иконка в трее)
Переключатель в системном трее: зелёная иконка — **Daily**, красная — **Hack**.

| | Daily | Hack |
|---|---|---|
| MAC-адрес | как обычно | случайный для подключений без собственной настройки MAC в NetworkManager |
| Входящий трафик | без ограничений | закрыт (nftables, разрешены только ответы на ваши запросы, DHCP и ICMPv6) |
| Тема KDE | Breeze Light | Breeze Dark |

- Режим хранится в `/run`, поэтому **после перезагрузки система всегда в Daily**.
- Переключение выполняет один скрипт `/usr/local/sbin/sath-mode`, для которого выдано правило sudo без пароля (только для него).
- Режим Hack **не делает тебя анонимным** сам по себе: Tor не заворачивает весь трафик, а лишь доступен как прокси. Это удобный набор настроек для работы с инструментами, а не гарантия приватности.

### 🔒 Чистая установка без «следов» live-режима
После установки Calamares автоматически удаляет live-пользователя `admin`, его sudo без пароля, автологин SDDM и домашнюю папку. Твой пользователь получает группу `sudo` и все настройки оформления (логотип, fastfetch, эффекты KWin) через `/etc/skel`.

## 🧰 Что внутри

- **База:** Debian Sid (`amd64`), ядро `linux-image-amd64`.
- **Рабочий стол:** KDE Plasma 6 на Wayland, SDDM, анимации окон (wobbly windows, размытие, magic lamp).
- **Терминал:** Kitty + `fastfetch` с ASCII-логотипом S.
- **Установщик:** Calamares с ярлыком на рабочем столе live-системы.
- **Игры:** Steam, GameMode, MangoHud, Vulkan (включая 32-бит библиотеки).
- **Драйверы:** `firmware-linux-nonfree`, PipeWire, опционально NVIDIA (`nvidia-open-kernel-dkms`, `nvidia-driver`).
- **Приложения:** Firefox ESR, Dolphin, Kate, Spectacle, Ark, p7zip, ffmpeg, btop, git, curl, nano.
- **Магазин приложений:** KDE Discover с поддержкой Flatpak и репозиторием Flathub.
- **Локали:** английская и русская.

## 🛠️ Как собрать ISO

Собирать нужно на Debian или Ubuntu (или в их виртуальной машине) с интернетом и примерно 25 ГБ свободного места.

1. Клонируй репозиторий:
   ```bash
   git clone https://github.com/sathmint/Sath-Linux.git
   cd Sath-Linux
   ```
2. При необходимости открой `build_sath.py` и поставь `INCLUDE_NVIDIA = False`, если драйверы NVIDIA не нужны.
3. Запусти сборку от root:
   ```bash
   sudo python3 build_sath.py
   ```
4. Готовый образ появится здесь:
   ```
   /var/tmp/sath_distro_build/SATH-Linux-2.3-amd64.iso
   ```
   **Скопируй его оттуда сразу:** рабочая папка очищается при каждом новом запуске сборки.

Образ гибридный и загружается и в BIOS, и в UEFI.

### Структура репозитория

| Файл | Назначение |
|---|---|
| `build_sath.py` | основной сборщик ISO |
| `sath_snapshots.py` | Btrfs-снапшоты, snapper, grub-btrfs, apt-хук |
| `sath_extras.py` | Sath Lab, режимы Daily/Hack, очистка live-пользователя |

Все три файла должны лежать в одной папке.

## 🚀 Тест в QEMU

```bash
qemu-img create -f qcow2 sath_disk.qcow2 30G
qemu-system-x86_64 -m 4G -enable-kvm -cpu host -smp 2 -vga virtio \
  -hda sath_disk.qcow2 -cdrom SATH-Linux-2.3-amd64.iso -boot d
```

Для проверки UEFI добавь `-bios /usr/share/ovmf/OVMF.fd` (нужен пакет `ovmf`).

- **Live-пользователь:** `admin`
- **Пароль:** `1`

Этот вход работает только в live-сессии и удаляется при установке на диск. При установке выбирай Btrfs (он предлагается по умолчанию), иначе откат из GRUB работать не будет.
